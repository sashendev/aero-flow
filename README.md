# AeroFlow ✈️

> A modern, real-time flight tracking platform built with Next.js, TypeScript, MapLibre, and the OpenSky Network API.

## 🌍 Overview

**AeroFlow** is a modern web application for exploring live air traffic around the world. Inspired by platforms like FlightRadar24, AeroFlow focuses on providing a clean, fast, and intuitive experience using open-source technologies.

The project is designed as a portfolio-quality application while following scalable software architecture and modern web development best practices.

## 🚀 Getting Started

### Prerequisites

* Node.js 20+
* npm, pnpm, or bun

### Installation

```bash
git clone https://github.com/sashendev/aero-flow.git

cd aero-flow

npm install
```

### Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
